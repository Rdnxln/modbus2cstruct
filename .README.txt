Этот проект - попытка создать аггрегатор данных от modbus-устройств
с помощью гибкой системы правил и маппинга в оконечную интерфейсную структуру.

Стадия MVP, Реализация функций для HR- и IR-регистров.

На старте (однократно) :
  - разбирается файл с правилами, для каждого правила
    строится AST-дерево вычислений (abstract syntax tree);
  - для упомянутых в правилах modbus-регистров составляется список modbus-запросов.

Во время рабочих циклов (многократно):
  - выполняется список modbus-запросов для актуализации регистров
    (связь с modbus-устройством реализована с помощью библиотеки libmodbus);
  - для каждого правила по его ast-дереву производится вычисление;
  - результаты вычисления, связанные с целевой структурой, копируются в нее;
  - целевая структура передается в приложение-аггрегатор (потребитель данных)
    (имитируется вызов интерфейсной функции).
